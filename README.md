# Client Brain Template

Clone this folder into a new private repository. Replace all `farmacia` placeholders and complete the manifest before ingestion.

## Ownership boundary

This repository is the client's complete operating record. It may contain internal-only records, but client exports and the client query agent include only records explicitly accepted for client access. Spatial Port reusable IP and internal account overlays stay outside this repository.

## Never add

- Secret values
- Spatial Port reusable software source code
- Videogo software or internal production methods
- Another client's information
